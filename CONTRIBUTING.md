# Contributing

Use Node.js 22+. There are no third-party npm dependencies to install.

1. Describe the actual problem or proposed creative workflow in an issue.
2. Make a focused branch and keep unrelated formatting or generated changes out.
3. Add meaningful tests for changes to rendering, configuration or frame timing.
4. Run `npm run build`, `npm run check`, and `npm test`.
5. Include the affected preset, a screenshot where helpful, and browser/OS details.
6. Describe any AI assistance and the checks you personally performed.

Do not submit private media, access tokens, fabricated usage metrics, purchased stars or synthetic contribution histories. New scenes must be deterministic, finite at all accepted inputs, periodic at the configured duration, and static at motion=0. Extend schema validation deliberately; backward-incompatible presets need a new schema version.

Keep both interface languages aligned. Prefer explicit playback and modest contrast changes. Changes to the generated files `studio.html` and `web/runtime-source.js` must come from `npm run build`.

By contributing, you agree that your contributions may be distributed under the project's MIT license. Maintainer review is required before acceptance. There is no guaranteed response time.
