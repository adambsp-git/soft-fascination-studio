# Roadmap

These are proposed future tasks, not existing features or external commitments.

## Before a public 0.1 release

- Complete manual desktop/mobile browser acceptance tests in VALIDATION.md.
- Review English/Chinese labels and keyboard-only operation with a second person.
- Confirm MIT licensing and project naming with the project owner.
- Publish to a separate public repository, run the supplied CI and tag the actual release.

## Small first contributions

- Document a real Safari, Firefox or mobile compatibility issue with a minimal preset.
- Improve error-message translations and export progress feedback.
- Add a preset gallery based on real artist submissions and explicit permissions.
- Add a deterministic renderer test for a reproduced edge case.

## Later, after real usage

- Frame rasterization/encoding integration with reproducible timing.
- Lightweight embeddable player packaging and measured performance work.
- New scenes built from documented artistic use cases.
- Optional installation inputs, only after defining protocols and local privacy needs.

Avoid adding telemetry to manufacture metrics. Track real issue reports, accepted contributions and voluntarily shared artworks. Do not promise research findings or grant acceptance.
