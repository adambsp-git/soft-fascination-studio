# Changelog

## 0.2.0 / 2026-09-22

- Added three offline starter presets matching the published examples.
- Added bounded 50-step undo/redo, including imports and resets; Ctrl/Cmd+Z and Shift+Ctrl/Cmd+Z work outside editable fields.
- Fixed root/subdirectory static hosting and added a standalone index entry.
- Added PNG progress feedback and distinguished blocked storage from invalid saved presets.
- Localized preview/settings landmarks; added history and deployment-path regression coverage.
- Updated publication evidence and practical contribution/hosting documentation.

## 0.1.0 candidate / 2026-09-21

Initial implementation, not yet a published GitHub release.

- Added deterministic rain, water and canopy SVG scenes.
- Added a bilingual local editor, presets, still exports and offline loop export.
- Added a standalone editor build and SVG frame-sequence CLI.
- Added tests, documentation, license and CI configuration.

No previous releases or maintenance history are claimed.
